# ProjectM Prototype(網頁測試版)

開發中原型的網頁測試版,僅供測試。

試玩:https://flassistant1.github.io/project-m-web/

- 建議用手機直向或電腦瀏覽器開啟;第一次點擊畫面後才會有聲音。
- 進度只存在各自的瀏覽器裡,換裝置或清除網站資料會從頭開始。
- 遇到錯誤時,右下角會出現「⚠ 錯誤 N」,請點開後按「複製」,連同操作步驟回報。

- 支援繁體中文、English、日本語、한국어:第一次開啟依瀏覽器語系決定(都不符合時用英文),遊戲內「設定」可切換;也可以在網址後面加 `?lang=en`、`?lang=ja`、`?lang=ko`、`?lang=zh-TW` 指定。
